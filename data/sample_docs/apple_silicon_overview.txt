Apple Silicon is a series of system on a chip (SoC) and system in a package (SiP) processors designed by Apple Inc. It uses the ARM architecture rather than Intel x86. The first Apple Silicon chip for Mac was the M1, announced in November 2020. Apple Silicon utilizes a Unified Memory Architecture (UMA) that allows the CPU, GPU, and Neural Engine to access the same memory pool without copying data across buses, significantly accelerating machine learning inference and local LLM execution.
